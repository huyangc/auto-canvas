## Goal

A notebook-only Playwright run, selected by `AUTO_CANVAS_E2E_NOTEBOOK=1` and invisible to the standard run, that drives the notebook production build of the editor at `/canvas` through a stand-in for silicon-notebook's Next.js rewrite, in front of the real canvas server in notebook mode and a stub notebook, and proves: without a session the page shows the signed-out page and touches no editor data; identification failures never fall back to single-user behaviour; every API request carries exactly the bearer of the session the document mounted, and nothing else carries any bearer; an account change or sign-out (another tab, the pre-event interval in the same tab, a 401, Back, the back/forward cache) removes the editor and stops sending at once. No product code changes.

Not in this task: per-user browser storage (T163). No assertion may claim that Alice's unsaved or restored work is invisible to Bob in browser storage, the tab strip or the canvas.
