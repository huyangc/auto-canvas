# CLQC 网表布线性能报告 · 第 1 轮

## 结果

基于 `d7b8eb0`，分支 `codex/clqc-routing-opt`。CLQC 导入后按编辑器默认预算运行时，端口选边的整图重布线从 213 次降至 12 次。**端口阶段达标，总耗时仍高于 20 秒。** 附件作为本轮实施简报，测量脚本和诊断计数位于临时目录。

| 指标                             |      main 基线 |  修改后第 1 次 |  修改后第 2 次 |
| -------------------------------- | -------------: | -------------: | -------------: |
| worker 计算时间（秒）            |          68.52 |          39.39 |          38.56 |
| 端口选边（秒）                   |          31.87 |           1.84 |           1.84 |
| 端口阶段整图重布线               |            213 |             12 |             12 |
| 交叉 / 折弯 / 线长               | 11 / 27 / 5710 | 11 / 27 / 5710 | 11 / 27 / 5710 |
| 未连接 / 悬空引脚 / 标注净距诊断 |      0 / 0 / 2 |      0 / 0 / 2 |      0 / 0 / 2 |

7 个非电源端口按同一顺序的侧向等级均为 `[1, 2, 2, 0, 1, 0, 2]`。两次默认结果的 `JSON.stringify(result)` SHA-256 同为 `932c1c33e3251a01b8624aebc0edc5b093429f0d9532a07027cdf7044b36e08d`。main 产物的摘要也与之相同。应用完整编辑事务后重新导出 SPICE，两次均逐卡核对了 19 个器件的全部 70 个引脚。布局器诊断均为空。

## 实施情况

| 步骤                | 状态       | 说明                                                                                                                                                                                                    |
| ------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 默认路径基线     | 完成       | 使用仓库中的原始 CDL、编辑器导入助手和 worker 核心，28 个实例，种子 1，24 次退火评估。初次调查约 77 秒，本轮基线约 68.52 秒。表中时间为 Node 上的本地计算时间，不含浏览器绘制。                         |
| 2. 重用和局部重布线 | 完成       | 每次规划复用清理前缀、布线引脚坐标和保留 ID 的键。空编辑沿用上一个预览。局部轨道搜索缓存单网规划，先在增量图上评分。候选提交前仍从原始文档整表重放并核对拓扑、名称和布线质量。                          |
| 3. 端口位置搜索     | 完成       | 多轮搜索共享成功和失败候选。先试镜像和端口滑动。R170 方向检查与可提前确定的对称项参与剪枝。仅移动端口时，尝试保留其他网络，仅重布受影响的信号树。超过 24 个实例时，整图与局部布线各有 12 次确定性额度。 |
| 4. 备用布局预算     | 试验后撤回 | 将备用方案的后处理预算减半会得到 28 个折弯、5910 线长，并使一个端口等级下降。保留完整端口预算而仅缩减其他几项，所得质量相同但耗时改善不明显。交付版保留原有终选预算。                                   |

## 取舍与环境

- 布线前使用交叉、折弯和线长预算。端口最终朝向会改变，几何剪枝保留最终朝向和线段出线方向的后验检查。事务完成后再核对名称、连接和障碍。
- 端口草图缓存限于本次后处理调用，避免复用其他接触策略的规划结果。未引入按估算分数重排候选的启发式。
- 普通套件使用本机回环和项目测试 PostgreSQL。沙箱内首次运行因环境权限失败，允许本地连接后完整重跑。依赖复用自锁文件相同的工作树，锁文件未改。
- 六项仓库检查通过。若要继续达到 20 秒，需要进一步降低两次终选中每个候选的完整布线与修复成本。直接减少备用方案的端口试验会使这份 CLQC 的成图质量退化。
