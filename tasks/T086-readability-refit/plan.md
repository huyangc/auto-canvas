# T086 — Readability scoring: close the blind spots and refit the weights

- Branch: `task/T086-readability-refit`
- Base: `main` at `1737221`
- Status: approved

## Goal

User decision (2026-11-15, "Fix the scoring first"): the frozen readability
score must see what the user sees. On main `1737221` the composite is dev
1.1946× / val 1.1498× human, yet the user flagged three drawings as clearly
worse than their human drawings, and the score barely notices:

| Drawing | Human / result score | What is wrong (Opus, renders in `tmp/three/`) |
| --- | --- | --- |
| `wvwmyesa4g` (dev, 10) | 0.006 / 0.012 | Feedback amplifier: signal flows right → left (`V_out` left, `V_in` middle), feedback capacitor looped around, bends 3 → 11, detour 0.19 → 1.22. |
| `6r2q6deeq9` (dev, 14) | 0.019 / 0.528 | Switched-capacitor bridge torn apart into a switch row and a source row; bends 5 → 18, crossings 0 → 3. |
| `bv9zwmd835` (dev, 12) | **0.231 / 0.118** | Degenerated differential pair not mirrored; R_S and I_SS pulled up to the R_D row; VDD and the tail Net drawn on one horizontal line separated by a small gap, reading as one wire. The score prefers the result. |

Bends, detour, symmetry mirroring and backward flow have zero weight
(`readability-weights.ts`), because the T070 fit (on `eb72cb1`) found they
did not separate human from result at that time. Since then the planner has
been optimised against the weighted metrics only. Two different Nets drawn
collinear end to end (reading as one conductor) are not measured at all.

The outcome of this task: a refitted, frozen readability score that (a)
measures collinear abutment of different Nets, (b) is refitted on current
main so blind spots get the weight the data supports, (c) scores all three
flagged drawings worse than human, and (d) separates human from result
better than the current weights on dev **and** val. The 1.2× goal will be
re-measured with the new score; it is expected to rise above 1.2× again.
That is accepted: the ruler is being corrected, not the layouts.

## Steps

1. **Investigate.** For the three drawings, list every metric (weighted and
   zero-weight) human vs result, and confirm which existing metric (if any)
   captures each defect in the table. Check whether `VISUAL_ROUTE_OVERLAP` or
   `VISUAL_AMBIGUOUS_JUNCTION` fires on `bv9zwmd835`'s VDD / tail line.
2. **New metric `collinearAbutment`.** Count pairs of wire segments of
   different Nets that lie on the same line (same y for horizontal, same x
   for vertical) and whose gap is at most two grid pitches (including
   touching), with no symbol between them; opportunities = segment pairs on
   the same line. Geometry and connectivity only. Unit tests: the
   `bv9zwmd835` pattern counts; a perpendicular crossing and a same-Net
   continuation do not.
3. **Refit.** Run the evaluator on main `1737221` code (this branch before
   any planner-visible change, plus the new metric) to produce a report, then
   `readability-fit.mjs --write --source-commit <that SHA>`. Keep the method
   (non-negative, dev-only). If a defect from the table still gets zero
   weight, report why with the paired differences; do not hand-set weights.
4. **Validate the new score** before touching anything else, against the old
   weights on the same report: pairwise discrimination (fraction of pairs
   where human scores lower) on dev and on val; the three flagged drawings
   must score worse than their human drawings; list the 20 drawings whose
   ratio to human rises most and the 20 that fall most, with the metric that
   drives each, and spot-check renders of five of each in the report.
   **Gate:** val discrimination must not fall below the old weights'.
5. **Re-evaluate the planner with the new weights** (it selects by the
   composite): full corpus, per-drawing comparison against main scored with
   the new weights, guards, large documents, held-out timing (alone). Report
   the new composite ratios (dev / val) — the new baseline for the goal.
